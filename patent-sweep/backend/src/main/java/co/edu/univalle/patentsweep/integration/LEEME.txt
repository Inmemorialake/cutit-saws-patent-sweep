Capa de integracion (Integration Layer del DAS)

En esta carpeta iran las conexiones con APIs externas: un cliente HTTP por cada una.
El service las usa; el controller nunca las llama directo.

Clientes previstos (aun no implementados en el Sprint 0):

  - MaterialesClient        API Materiales/Formulas.
                            GET /formulas/{codigo}: detalle de una formula y sus componentes.
  - FuentePatentesClient    API de patentes (simulada con WireMock).
                            GET /patentes/buscar: busca patentes por terminos, clasificaciones y fecha.
  - NotificacionesClient    API Notificaciones.
                            POST /notificaciones: envia la alerta de un conflicto de patente.

Estructura sugerida:

  integration/
    port/   interfaces que usa el service (por ejemplo, FuentePatentesPort)
    dto/    objetos con la forma de lo que envian o devuelven las APIs externas
    *.java  los clientes, que implementan los puertos y traducen los errores HTTP

Las URLs base se configuran con las variables MATERIALES_URL, NOTIFICACIONES_URL
y FUENTE_PATENTES_URL.
