# HU-04 — Consulta del estado de barrido de una fórmula

| Campo | Valor |
|---|---|
| **Rol** | API de Fabricación (integración REST) y usuario autenticado de Patent Sweep (GUI) |
| **Prioridad / Puntos** | Must / 5 · Sprint 1 · Se construye después de HU-02 |
| **Historia** | Requiero consultar el estado del último barrido de patentes registrado para una fórmula, para saber si puede pasar a fabricación. |
| **Idea clave** | El estado **no se guarda**: se calcula en cada consulta a partir de los conflictos, las evaluaciones y el historial de revisiones (ADR-003). Es la respuesta que Fabricación usa para autorizar la producción. |

## 2. Endpoint y vista web

### Vista web (`static/`)
- **Navegación:** **Patentes > Estado de Barrido** (cualquier rol autenticado).
- **Formulario:** campo `formulaId` con validación `form-NNN` y botón **«Ver Estado de Barrido»**.
- **Resultado:** el estado como insignia, `fechaUltimaRevision`, el mensaje y la tabla **Alertas activas** (`conflictoId`, `tituloPatente`, `fechaDeteccion`); cada fila enlaza al detalle de HU-08 (enlace provisional).
- **Sin alertas:** muestra el mensaje literal «La fórmula no tiene alertas activas».

### `GET /api/v1/patentes/estado/{formulaId}`

- **Consumidor:** API de Fabricación o usuario autenticado (JWT, cualquier rol).
- **Entrada:** `formulaId` en la ruta, obligatorio, `@Pattern("^form-\\d{3}$")`.

**200 OK**
```json
{
  "formulaId": "form-001",
  "estado": "CONFLICTO_DETECTADO",
  "fechaUltimaRevision": "15/10/2026 10:30:00",
  "alertasActivas": [
    { "conflictoId": "123456",
      "tituloPatente": "Aleación para cadenas de corte",
      "fechaDeteccion": "15/10/2026 10:30:00" }
  ],
  "mensaje": "Estado de la fórmula consultado correctamente"
}
```

- `estado`: `CONFLICTO_DETECTADO | PENDIENTE_REVISION | LIBRE | NO_PROCESADO`.
- `fechaUltimaRevision`: último evento del historial de cualquier origen, `dd/MM/yyyy HH:mm:ss`; `null` si el estado es `NO_PROCESADO`.
- `alertasActivas`: conflictos `DETECTADO` de la fórmula, del más reciente al más antiguo; `[]` si no hay.

**Errores** (`ProblemDetail` con `title`, `detail` y `traceId`):

| Código | Cuándo | `detail` exacto |
|---|---|---|
| 400 | `formulaId` sin formato `form-NNN` | `El identificador de la fórmula no es válido` |
| 404 | La fórmula no existe en Materiales | `La fórmula consultada no fue encontrada` |
| 503 | Materiales no responde en 5 s o el circuit breaker está abierto | `No fue posible verificar la fórmula. Intente nuevamente` |
| 500 | Fallo de la base de datos de Patent Sweep | `No fue posible obtener el estado de la fórmula. Intente nuevamente` |
| 401 | Sin token o token inválido | Respuesta estándar de seguridad |

### Endpoints que consume
- `GET /formulas/{formulaId}` (Materiales/Fórmulas): existencia y versión vigente de la fórmula.

## 3. Flujo y reglas de estado

1. Validar `formulaId` → 400.
2. `MaterialesClient.verificarFormula(formulaId)` (1 intento, 5 s) → 404 / 503. Devuelve la versión vigente.
3. Leer la última revisión del historial (cualquier origen) → `fechaUltimaRevision`.
4. Aplicar las reglas **en este orden**:

| Orden | Condición | Estado |
|---|---|---|
| 1 | Hay al menos un conflicto `DETECTADO` para la fórmula (por pareja, sin filtrar la versión; ADR-012) | `CONFLICTO_DETECTADO` |
| 2 | Hay una evaluación `EN_PROCESO` o `PENDIENTE_DE_ENVIO` (HU-03) | `PENDIENTE_REVISION` |
| 3 | Nunca se revisó, la última revisión es `FALLO_TECNICO` o la última revisión es de otra versión (ADR-004) | `NO_PROCESADO` |
| 4 | En cualquier otro caso (revisada, sin conflictos vigentes o todos `DESCARTADO`) | `LIBRE` |

5. Mapear a DTO y responder 200. **No se persiste nada** (ADR-003).

## 6. Decisiones y discrepancias (ver `docs/discrepancias.md`)
- **D-3 Nombre del estado:** `NO_PROCESADO` (HU-04 y DAS) en lugar de `NO_PROCESADA` (PB).
- **D-8 Ruta:** solo `GET /estado/{formulaId}`; la ruta `/estado/{id}` del Sprint 0 se retiró.
- **D-9 Unicidad:** las alertas cuentan los conflictos `DETECTADO` por pareja, sin filtrar la versión (ADR-009, ADR-012).
- **Versión no revisada (ADR-004):** si la última revisión corresponde a otra versión de la fórmula, la versión vigente se considera no revisada (`NO_PROCESADO`). El PB no lo menciona de forma explícita; se deriva de que el estado describe la fórmula vigente.
